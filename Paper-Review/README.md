## 리뷰 구성

각 리뷰는 [리뷰 템플릿](./_template/review-template.md)의 항목(논문 정보, 한 줄 요약, 연구 배경, 핵심 아이디어, 모델 구조, 실험 결과, 강점과 한계, 내 연구에 적용할 점, 참고 자료)을 따릅니다. 모델 구조 절은 텐서 흐름과 모듈별 설계 이유까지 설명하는 것을 기본으로 합니다. 구조 설명의 예시는 [EWT 리뷰](./Image-Restoration/2023-EWT/)입니다.

### 근거 표기

구조 설명처럼 논문의 내용과 리뷰어의 해석이 섞이기 쉬운 곳에서는 다음 표기로 근거를 구분합니다.

| 표기 | 의미 |
|---|---|
| **[논문]** | 본문, 수식, 표에서 직접 확인한 내용 |
| **[그림]** | 원문 그림(Fig.)에서 확인한 내용 |
| **[해석]** | 리뷰어가 구조적으로 추론한 내용 |
| **[예시]** | 이해를 돕기 위한 설명용 예시 |
| **[코드]** | 구현 저장소에서 확인한 내용 |
| **[미확인]** | 확인되지 않은 내용 |

## 폴더 구성

```text
Paper-Review/
├── README.md              # 이 목록
├── REVIEW_GUIDE.md        # 작성 가이드
├── _template/             # 리뷰 템플릿
└── 분야/발표연도-모델명/
    ├── README.md          # 리뷰 본문
    └── images/            # 원문 그림 등 (필요할 때만)
```

## 리뷰 작성 방법

논문별로 `발표연도-모델명` 폴더를 만들고 [리뷰 템플릿](./_template/review-template.md)을 복사해 `README.md`로 작성합니다. 필요한 이미지는 해당 논문의 `images/` 폴더에 둡니다. 원문 그림은 라이선스를 확인하고 출처를 표기한 뒤에만 사용합니다.

자세한 구조와 작성 원칙(근거 표기, 모델 구조 설명 작성법, 그림 사용 조건, 공식 코드 확인, 작업 후 점검)은 [논문 리뷰 작성 가이드](./REVIEW_GUIDE.md)를 참고합니다.
