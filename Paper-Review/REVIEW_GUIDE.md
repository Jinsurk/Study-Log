# 논문 리뷰 작성 가이드

이 문서는 다른 컴퓨터나 새로운 작업 세션에서도 Paper-Review의 구조와 작성 방식을 일관되게 유지하기 위한 안내입니다.

## 시작하기

1. 리뷰할 논문 원문을 확인합니다. 저자, 연도, 논문 버전, 방법과 실험 수치를 원문에서 확인합니다.
2. [리뷰 템플릿](./_template/review-template.md)을 사용하고, 분량과 구성은 [EWT 리뷰](./Image-Restoration/2023-EWT/)를 참고합니다.
3. 논문 주제에 맞는 분야 폴더를 선택합니다. 기존 분야에 넣기 어렵다면 적절한 새 분야 폴더를 만듭니다.
4. 리뷰 파일을 작성하고 [목록 README](./README.md)에 한 줄을 추가합니다.

## 폴더 구조와 파일 이름

```text
Paper-Review/
├── README.md
├── REVIEW_GUIDE.md
├── _template/
│   └── review-template.md
└── Image-Restoration/
    └── 2023-EWT/
        ├── README.md
        └── images/             # 이미지가 필요할 때만 생성
```

- 리뷰 경로: `Paper-Review/분야/발표연도-모델명/README.md`
- 예: `Paper-Review/Image-Restoration/2023-EWT/README.md`
- 모델명이 불분명하면 짧고 알아보기 쉬운 논문 제목을 사용합니다. 연도는 검토한 논문의 공개·발표 연도를 확인해 기재합니다.
- GitHub는 빈 폴더를 저장하지 않으므로 `images/`는 실제 이미지가 필요할 때 만듭니다.

## 리뷰 작성 원칙

- 한국어로 작성하고 기술 용어와 모델명은 필요한 경우 원문 표기를 함께 사용합니다.
- 템플릿의 항목을 유지하되, 논문에 맞지 않는 항목은 그 이유를 간단히 적습니다.
- 연구 배경, 핵심 아이디어, 구조, 실험, 강점과 한계를 독립적으로 읽을 수 있도록 정리합니다.
- EWT 리뷰 정도의 밀도를 기본으로 하되 논문의 복잡도에 따라 조절합니다. 표와 간단한 흐름도를 활용할 수 있습니다.
- 수치에는 데이터셋, 실험 조건, 비교 모델 및 논문 표·그림 번호를 가능한 한 함께 적습니다. 서로 다른 조건의 결과는 직접 비교하지 않습니다.
- 논문이 주장하는 내용, 원문에서 확인한 결과, 리뷰어의 해석을 구분합니다. 확인하지 못한 사항은 추측하지 않고 미확인이라고 표시합니다.
- 실제 코드, 데이터, 발표 학회 또는 최신 버전을 확인하지 않았다면 확인한 것처럼 적지 않습니다. 논문 링크와 검토한 버전을 명시합니다.
- 「내 연구에 적용할 점」은 연구 아이디어로 표시하고, 논문에서 입증한 결과처럼 서술하지 않습니다.
- 논문 PDF나 그림을 저장소에 넣기 전 공개·재사용 조건을 확인합니다. 필요하면 원문 링크 또는 직접 만든 설명 그림을 사용합니다.

## 전체 목록 업데이트

`Paper-Review/README.md`의 해당 분야 표에 연도, 논문명, 핵심 키워드와 리뷰 상대 링크를 추가합니다. 기존 항목은 유지하고, 동일 논문이 이미 있는지 먼저 확인합니다.

```markdown
| 2023 | EWT | DWT, Transformer, Denoising | [리뷰](./Image-Restoration/2023-EWT/) |
```

## 다른 랩탑에서 작업하기

- GitHub에서 작업할 때는 이 가이드와 템플릿, EWT 예시를 열어 참고합니다. GitHub 계정에 저장소 접근 및 수정 권한이 필요합니다.
- 로컬에서 작업할 때는 저장소를 clone하거나 기존 저장소에서 최신 `main`을 pull한 뒤 작업합니다. 로컬 변경은 GitHub에 push하기 전까지 다른 랩탑에 자동으로 나타나지 않습니다.
- 기존 변경 사항을 먼저 확인하고 보존합니다. 변경을 공유할 때는 별도 브랜치와 PR로 검토할 수 있습니다.
- 작업 후 리뷰와 목록 링크가 올바른지, 원문 출처와 표의 조건이 들어갔는지 확인합니다.

## 요청 예시

> 이 논문을 Paper-Review/REVIEW_GUIDE.md와 review-template.md에 따라 한국어로 리뷰해 줘. EWT 리뷰의 분량과 구성도 참고하고, 적절한 분야의 `발표연도-모델명/README.md`로 정리해 줘. 기존 내용을 보존하면서 목록 README에도 추가하고, 논문에서 확인한 사실과 적용 아이디어를 구분해 줘.
