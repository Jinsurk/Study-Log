# 1주차 — Fundamentals

학습 대화에서 실습 완료를 확인한 주제:

- GCC 컴파일과 실행, 경고 옵션, `int main(void)`와 반환값
- 정수·실수·문자 자료형, `sizeof`, signed/unsigned, `uint8_t`
- 16진수 출력과 정수 변환, 정수 나눗셈과 실수 나눗셈
- 조건문, 반복문, 함수 선언·정의·호출, 헤더와 소스 분리
- 함수 기반 CLI 계산기
