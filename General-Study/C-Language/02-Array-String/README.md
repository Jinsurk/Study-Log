# 2주차 — Array & String

학습 대화에서 확인한 결과:

- 정수 배열 `{10, 20, 30, 40, 50}`의 합계: 150
- 해당 환경에서 `sizeof(int)`는 4바이트, 원소 5개 배열은 20바이트
- 배열 인덱스는 0부터 4까지이며, 인접 원소 주소는 4바이트 차이
- 문자열 `Jetson`은 문자 6개와 끝의 `\0`를 포함해 `char` 배열 7바이트
- `strlen`은 널 종료 문자 이전의 길이, `sizeof`는 해당 배열의 전체 크기

배열 크기와 주소 간격은 해당 자료형·실행 환경에 따른다. 모든 시스템의 `int`가 4바이트라고 일반화하지 않는다.

문자열 비교 학습까지 진행했으나 이후 실행 완료는 미확인이다. 실제 `array_memory.c`, `string_basic.c` 등의 소스는 확보 후 추가한다.
